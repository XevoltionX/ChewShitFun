### 遇到的一些问题和思考
-  **惊人的emoji表情使用量** — AI味太浓,本来以为下了front-design的SKill能好看不少,结果AI不熟悉Uni-App魔改过的语法,还是太依赖自带表情修饰,反而Skill起反面效果

-  **打包后预览差异大** — 我手机老的缘故,一方面也是安卓emoji确实比苹果和微软的表情丑的多,只好提前固定字体的让ai重构一下一些表情,但是是拿python画的,反正感觉挺一般,一些删除和隐藏再旧的sdk里也不起效果,自带tarbar没消掉把导航删了才行
  
-  **小语种适配差** — 相比之前拿java做的和python做的对比,DeepSeekV4在Uni-App上表现效果像退化了一个版本

-  **架构设计左右脑互博** — 涉及到想要进行复杂一点的架构和业务分析,最好还是用多Agent协作模式,单Agent同时负责出谋划策和反驳非常容易混乱,反驳也像是形式主义一下

## 📱 简介

ChewShitFun 是一款"严肃"的肠道健康追踪应用。通过长按马桶、拖拽气泡选择维度的创新交互，轻松记录每一次"安放C4任务"。内置 ShitMan 拉屎侠智能分析引擎，根据历史数据给出个性化饮食建议。

## ✨ 功能

- 🔐 **假装登录** — 预设用户名，自己人才能进
- 📅 **屎诗日历** — 农历+十二时辰+四季，点击看详情
- 💩 **气泡划选记录** — 长按马桶，拖拽4层气泡选粘稠度/臭味/量/颜色
- 🦸 **ShitMan 拉屎侠** — 7天数据分析，5维度健康建议
- 📜 **岁月屎书** — 待办清单，打勾删除
- 🏆 **成就徽章** — 5种成就，解锁条件各异
- 🌙 **日/夜间模式** — 一键切换，护眼拉屎
- 📳 **振动+音效** — 每步操作都有反馈

## 🛠 技术栈

- **框架**: uni-app (Vue 3 + Composition API)
- **状态管理**: Pinia
- **农历**: solarlunar
- **平台**: Android / iOS / H5

## 🎮 操作指南

| 操作 | 方式 |
|------|------|
| 记录拉屎 | 底部中间💩大按钮 → 长按马桶 → 拖拽选4层气泡 → 松手 |
| 取消记录 | 拖到顶部或底部❌取消区松手 |
| 查看详情 | 日历页点击日期格子 |
| 切换月份 | 日历页点 ‹ › 箭头 |
| 翻牌 | 底部 Tab 切战绩/记录/用户 |
