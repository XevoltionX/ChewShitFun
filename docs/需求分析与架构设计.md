# ChewShitFun — 需求分析与架构设计

> 版本：v1.0 | 日期：2026-05-20 | 状态：设计阶段

---

## 一、项目概述

### 1.1 产品定位

一款面向熟人小圈子的趣味拉屎记录 App。核心体验是用幽默轻松的方式追踪每日排便习惯，自动给出饮食建议。不是严肃的健康工具，而是一个「让自己和朋友会心一笑」的小玩意。

### 1.2 目标用户

- 自己和 3~5 个朋友
- 拉完随手一记，不需要专业医学知识
- 朋友之间通过分享图互相吐槽

### 1.3 核心卖点

- **长按划选气泡记录**：拉完屎按住图标 → 逐级冒泡选指标 → 松手即记录，一秒完成
- **💩 月历视图**：每天拉几次一目了然，格子颜色深浅 + 💩 emoji 标记
- **幽默饮食建议**：每天一句吐槽式建议 + 每周「便报」总结
- **趣味成就系统**：解锁徽章，数据可视化
- **伪装登录**：仪式感拉满的假登录页，选预设用户名进入

## 二、功能需求

### 2.1 伪装登录

| 项 | 说明 |
|----|------|
| 背景 | 深蓝色 (`#1a2744`) 全屏背景 |
| 输入框 | 输入用户名，下方提示 3~5 个预设可用名 |
| 默认值 | 自动填入上次登录的用户名 |
| 进入按钮 | 棕色 (`#8B5E3C`)，点击后进入主页 |
| 验证逻辑 | 无真实验证，匹配预设名单即通过 |

### 2.2 底部导航

三栏 TabBar：

| Tab | 图标 | 功能 |
|-----|------|------|
| 日历 | 📅 | 月历视图，查看历史记录 |
| 记录 | 💩 | 长按划选气泡，新增记录 |
| 用户 | 👤 | 统计数据 + 成就 + 分享 |

### 2.3 日历页（默认首页）

- **月历视图**：当月完整日历，可左右滑动切换月份
- **格子标记**：
  - 有记录的日子显示 💩 emoji
  - 格子背景色随次数加深（无→白 / 1次浅棕 / 2次中棕 / 3次+深棕）
  - 格子边框同步加深，保证边界清晰可见
  - 格子圆角 6px，间距 6px
- **点击日期**：弹出气泡卡片（从日期位置冒出），展示：
  - 当天每次记录（时间 + 粘稠度/臭味/量/颜色）
  - 底部一句饮食建议
  - 点击卡片外任意位置关闭
- **暂无记录的日期**：气泡卡片提示「这天还没开张~」

### 2.4 记录页（气泡划选交互）

这是 App 最核心的交互，流程如下：

```
长按中央卡通💩图标
  │
  ├─ 图标上方出现 ❌ 取消区（拖到此处取消记录）
  │
  └─ 第1层气泡冒出：粘稠度（黄绿 / 浅棕 / 深棕 / 偏黑）
       │  手指划到目标 → 选中高亮
       │
       └─ 第2层气泡冒出：臭味（没啥味 / 适中 / 有点臭 / 生化武器）
            │  手指划到目标 → 选中高亮
            │
            └─ 第3层气泡冒出：量（一点点 / 正常量 / 量很大）
                 │  手指划到目标 → 选中高亮
                 │
                 └─ 第4层气泡冒出：颜色（黄绿 / 浅棕 / 深棕 / 偏黑）
                      │  手指划到目标 → 选中高亮
                      │
                      └─ 松手 → 记录完成！
```

**关键规则：**
- 每选完一个指标自动冒出下一层气泡
- 中途松手：已选指标保留，未选指标取最常见默认值（正常/适中/正常量/浅棕），直接记录
- 手指拖到顶部 ❌ 图标松手：取消本次记录，类似微信语音上滑取消
- 记录完成后弹出提示：**「✅ 已完成安放C4任务」**
- 记录自动保存当前时间戳

### 2.5 用户页

#### 统计区
- 本月总次数
- 本月有记录天数
- 最常见的粘稠度 / 臭味类型
- 月度趋势小图（每周次数变化，简单柱状）

#### 成就徽章
| 成就 | 解锁条件 |
|------|----------|
| 🎖 初次安放 | 完成第 1 次记录 |
| 🔥 稳定输出 | 连续 7 天有记录 |
| ☣️ 生化武器专家 | 累计 10 次臭味达到「生化武器」 |
| 👑 打卡狂魔 | 一个月内每天都有记录 |
| 💎 五彩斑斓 | 四种颜色指标都出现过 |

#### 分享功能
- 生成「月度战报」图片：
  - 当月总次数 + 天数
  - 本周趋势柱状图
  - 已解锁成就展示
  - 一句幽默总结（如「本月共安放C4 ×24，荣获生化武器专家称号」）
  - 分享到微信/保存到相册

### 2.6 饮食建议

#### 触发时机
| 场景 | 方式 |
|------|------|
| 每日卡片 | 点击日历日期弹出的气泡卡片底部显示 |
| 每周便报 | 每周末弹出周度总结，给出饮食建议 |

#### 建议规则（示例）
| 触发条件 | 建议文案风格 |
|----------|-------------|
| 连续 3 天粘稠度偏稀 | 「肠胃最近在抗议，多吃香蕉/米饭稳住它」 |
| 连续 3 天偏干硬 | 「水分告急！多喝水多啃蔬菜，别让马桶太辛苦」 |
| 臭味持续「生化武器」 | 「蛋白质摄入该减减了，肠道都快成化工厂了」 |
| 连续 5 天一切正常 | 「最近状态很稳，继续保持！你的肠道很爱你」 |
| 当天多次（3次+） | 「今天出货量有点大，是不是吃坏肚子了？」 |

## 三、非功能需求

| 项 | 要求 |
|----|------|
| 平台 | 优先 Android APK，后续可扩展微信小程序 |
| 数据存储 | 纯本地 `uni.storage`，不依赖后端 |
| 离线可用 | 所有功能离线正常运行 |
| 性能 | 日历滑动流畅，气泡动画 60fps |
| 包体积 | 目标 < 10MB |
| 用户数据隔离 | 不区分用户（预设用户名仅仪式感，数据共享） |

## 四、技术架构

### 4.1 技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | Uniapp (Vue 3) | 一套代码多端打包，优先 Android |
| 状态管理 | `pinia` | Vue 3 官方推荐，轻量 |
| 本地存储 | `uni.storage` / `uni.setStorageSync` | 原生同步 API，数据量小无需 SQLite |
| 分享图 | `html2canvas` 或 `uni.canvasToTempFilePath` | 前端生成图片 |
| CSS 方案 | SCSS + CSS Variables | 主题色统一管理 |
| 图标 | Emoji 原生 + 少量自定义 SVG | 减少图标库依赖 |

### 4.3 数据模型

```
poop_records: [
  {
    id: string,           // 唯一 ID (时间戳+随机)
    timestamp: number,    // 记录时间戳
    consistency: string,  // 粘稠度: '黄绿' | '浅棕' | '深棕' | '偏黑'
    smell: string,        // 臭味: '没啥味' | '适中' | '有点臭' | '生化武器'
    amount: string,       // 量: '一点点' | '正常量' | '量很大'
    color: string         // 颜色: '黄绿' | '浅棕' | '深棕' | '偏黑'
  }
]

user_config: {
  lastUsername: string,   // 上次登录的用户名（自动填入）
  presetNames: string[]   // 预设用户名列表
}

achievements: {
  [key: string]: {
    unlocked: boolean,
    unlockedAt: number    // 解锁时间戳
  }
}
```

### 4.4 数据流

```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  记录页      │───▶│  pinia store │───▶│ uni.storage │
│ (气泡划选)   │    │  (poop.js)   │    │  (持久化)    │
└─────────────┘    └──────┬───────┘    └─────────────┘
                          │
                    ┌─────┴─────┐
                    │           │
              ┌─────▼──┐  ┌────▼──────┐
              │ 日历页  │  │  用户页    │
              │ (读取)  │  │ (统计读取) │
              └─────────┘  └───────────┘
```

- 记录页写入 → pinia store 更新 → 同步写入 `uni.storage`
- 日历页和用户页从 pinia store 读取（store 初始化时从 storage 加载）
- 成就检测在每次记录后触发

### 4.5 核心交互状态机（气泡划选）

```
IDLE ──长按──▶ LAYER_1（粘稠度气泡冒出）
                 │ 手指划到选项
                 ▼
               LAYER_2（臭味气泡冒出）
                 │ 手指划到选项
                 ▼
               LAYER_3（量气泡冒出）
                 │ 手指划到选项
                 ▼
               LAYER_4（颜色气泡冒出）
                 │ 手指划到选项 → 松手
                 ▼
               COMPLETE → 显示「已完成安放C4任务」→ IDLE

任意阶段 ──拖到❌松手──▶ CANCEL → IDLE
任意阶段 ──未选完松手──▶ COMPLETE（剩余取默认值）
```
