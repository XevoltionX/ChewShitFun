# 用户页设计

## 概述
重写 `pages/user/index.vue`，展示用户本月战报统计、成就徽章、分享入口。

## 数据来源
- `usePoopStore` — 所有记录数据
- `getUserConfig` — 当前用户名
- 全部 computed，无需额外请求

## UI 区块

### 1. 用户名
- 顶部显示 `👤 {lastUsername}`
- 从 `getUserConfig().lastUsername` 读取

### 2. 本月战报
- 总次数：当月 records 总数
- 天数：当月有记录的天数 / 当月总天数
- 最常见：统计当月 records 中出现最多的 `consistency` 和 `smell`（mode）
- 周趋势：当月按周（1-7, 8-14, 15-21, 22-31）分组计数，4 根 CSS 柱状条，高度与次数成正比

### 3. 成就徽章
5 个成就，从 store.records 计算解锁状态：

| 徽章 | 名称 | 解锁条件 |
|------|------|----------|
| 🎖 | 初次安放 | 总记录数 >= 1 |
| 🔥 | 稳定输出 | 存在连续 7 天有记录 |
| ☣️ | 生化武器专家 | smell="生化武器" 累计 >= 10 |
| 👑 | 打卡狂魔 | 任一个月内每天都有记录 |
| 💎 | 五彩斑斓 | 四种 color 值都出现过 |

已解锁：正常色 + 发光效果；未解锁：灰色 + 锁定图标

### 4. 分享按钮
- 棕色按钮 "📸 生成月度战报"
- 点击弹出 toast "功能开发中..."
